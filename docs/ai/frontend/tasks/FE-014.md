# FE-014 Task Packet — Route-Level Code Splitting + Performance Hardening

- TASK ID: FE-014
- GOAL: Stop shipping every InsightInk feature page in one initial JavaScript bundle while preserving routing, session guards, RTL/LTR, and direct URL behavior.
- BASE COMMIT: `4c49db0762547e2c079c988a6dd9edb0a61f8e39` (`feat(frontend): add moderator workspace`).
- STATUS: Implementation complete; pending user acceptance before checkpoint commit/push.

## Why this milestone exists

FE-013 production build:

```text
main JS raw   ~540.16 KB
main JS gzip  ~158.34 KB
```

Vite emitted the >500 KB chunk warning.

The application now has enough independent screens that loading all page implementations before the user visits them is unnecessary.

## Split strategy

Keep the persistent application core eager:

- React/ReactDOM
- router runtime
- i18n
- TanStack Query provider
- RootLayout/header
- session/auth route guards
- shared API/session core.

Lazy-load page-level route modules:

- Landing
- Idea detail
- Search
- Creator profile
- Login
- Register
- authenticated Reader home
- Latest
- Library
- Interests onboarding
- Content-language onboarding
- Moderation queue
- Moderation report detail
- Not Found.

No new dependency was added.

## Loading UX

- RootLayout stays mounted while a lazy route module is fetched.
- The route stage is wrapped in React Suspense.
- A dedicated localized route-loading state is used:
  - English: Loading this view…
  - Persian: در حال بارگذاری این بخش…
- Existing session loading continues to use the separate Checking your session state.

This distinction prevents route-code loading from being mislabeled as an authentication check.

## Scope boundaries

FE-014 does not:

- change visual design;
- change API contracts;
- change backend files;
- add service workers/PWA caching;
- add speculative route prefetching;
- manually split vendor libraries merely to create more files;
- change the Vite warning threshold.

Future performance work should be measurement-driven rather than chunk-count-driven.

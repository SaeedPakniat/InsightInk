## Goal

Add restrained interaction polish without redesigning InsightInk, increasing UI complexity, or weakening old-device/accessibility goals.

The existing project already had:

- button/card hover and press transitions;
- route-entry animation;
- the bilingual language-morph animation;
- skeleton/loading animation;
- a global reduced-motion duration override.

FE-024 therefore focuses only on interaction gaps rather than adding broad page animation.

## Delivered

### Disclosure motion

Account menu and compact mobile navigation now use the same lightweight entrance motion:

- animation: `disclosure-enter`;
- duration: 180 ms;
- easing: existing `--ease-out`;
- opacity + 6px vertical settle only;
- no blur/filter;
- no animation library;
- no layout-affecting properties.

The account trigger chevron now transitions smoothly when expanded/collapsed.

### Trigger and menu feedback

Added restrained transition/press feedback to:

- account trigger;
- mobile menu trigger;
- account menu links;
- account logout;
- mobile logout;
- public auth links in desktop/mobile shell.

Interaction feedback remains based on existing color/border/scale language.

### Idea and account affordance polish

Added subtle feedback for:

- Account save/status feedback;
- language preference persistence error;
- account menu error;
- Idea Share success/error feedback;
- Idea report trigger press state;
- Idea Detail back-link color transition;
- IdeaCard “Read full” directional arrow.

The IdeaCard arrow moves in the correct reading direction:

- LTR -> +2px;
- RTL -> -2px.

No content direction behavior changed.

### Reduced motion

The existing `prefers-reduced-motion: reduce` block is strengthened.

In addition to near-zero global transition durations, FE-024 explicitly removes animation from:

- route entry;
- account menu;
- mobile navigation;
- language persistence error;
- account menu error;
- account status feedback;
- Share feedback;
- comment composer loading shimmer;
- Idea skeletons;
- topic skeletons;
- spinner.

It also removes transform-based lift/press movement from representative interactive surfaces such as:

- buttons;
- account/mobile triggers;
- navigation links;
- account links/logout;
- account preference links;
- topic selectors;
- feed tabs;
- moderation filters/cards;
- Idea cards;
- Spark/Save controls;
- IdeaCard directional arrow;
- report trigger.

The language toggle already avoids its morph overlay in reduced-motion mode through runtime `matchMedia` handling; that behavior remains unchanged.

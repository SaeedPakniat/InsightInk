## Application shell

`RootLayout` now provides a persistent, sticky application header with separate compact and desktop navigation treatments.

Authenticated navigation contains:

- Home (`/app`)
- Explore (`/explore`)
- Search (`/search`)
- Library (`/library`)
- Creator Studio (`/studio`)
- Moderation (`/moderation`) only when `capabilities.can_moderate` is true.

Anonymous navigation contains only public Home and Search destinations plus Log in and Create account actions. Active routes use both a visible marker and `aria-current="page"`.

At compact widths the desktop navigation is replaced by a real button controlling a lightweight slide-down panel. The panel closes after navigation, on Escape, on route changes and on outside pointer interaction. Escape restores focus to the disclosure trigger. The header and panels use logical CSS positioning for LTR/RTL behavior and avoid backdrop filters or new runtime dependencies.

## Account control

Authenticated sessions receive an account trigger and non-modal anchored account panel containing:

- resolved display identity and email;
- the existing language toggle and morph behavior, kept directly visible in the persistent header rather than moved into a dropdown/menu;
- useful existing Home and Creator Studio destinations;
- pending/disabled Sign out state;
- localized retryable Sign out failure feedback.

Successful logout calls the existing `logout()` API, removes non-session React Query cache entries, stores a null session, closes transient panels and replaces navigation with `/`.

`CurrentUser.avatar_url` is typed as optional and nullable so the frontend works safely before the backend field is deployed. `AccountAvatar` displays the remote account avatar when present. Otherwise it derives deterministic initials (at most two Unicode characters) from `display_name`, falling back to the email local part for blank names. CreatorProfile avatar data is not reused.

## Accessibility and responsive behavior

- navigation and popover triggers are native buttons with localized labels, `aria-expanded` and `aria-controls`;
- menus remain non-modal and keyboard reachable without a fragile focus trap;
- Escape dismissal restores trigger focus;
- all navigation links retain visible focus treatment;
- compact touch controls are at least 44 CSS pixels;
- sticky offset is included in document scroll padding;
- panels use bounded viewport height and scrolling;
- account panels use viewport-safe compact insets and logical desktop anchoring;
- English LTR and Persian RTL use the same semantic document order.

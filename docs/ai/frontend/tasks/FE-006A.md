# FE-006A Task Packet — Reader Content Languages

- TASK ID: FE-006A
- GOAL: Integrate BE-LANG-001 into the frontend so readers can choose which content languages they want to discover, independently from the Persian/English UI language.
- BASE COMMIT: `19f578f0c301ff6aafa4764cd249938dbab7c0b8`.
- BACKEND CONTRACT COMMIT: `9fd181c1e6d97566c6ef2c90f2fe774b6947fd68`.
- API CONTRACT:
  - public `GET /api/v1/languages/` -> active canonical language catalog.
  - authenticated `GET /api/v1/me/languages/` -> saved reader content languages.
  - authenticated `PUT /api/v1/me/languages/` body `{languages:string[]}` -> replacement preference set.
  - authenticated feed/recommendations already respect stored content-language preferences.
  - direct public Idea detail remains language-preference independent.
- PRODUCT RULE: UI language != content languages != Idea language != Source language.
- ONBOARDING: registration -> interests -> content languages -> app. Later interest edits return directly to app rather than forcing onboarding again.
- EXISTING USERS: Edit languages action on reader home opens the same protected preference editor.
- CATALOG UX: searchable across English name, Persian name, native name and code; render canonical backend order; selected count + available count; native names use their own lang/dir; zero-selection warning because backend intentionally allows an empty list.
- LARGE-CATALOG UX: sticky compact Save languages control while browsing the 62-language catalog.
- CONTENT UI: IdeaCard and Idea Detail surface the Idea language using the canonical catalog; catalog query is globally cached for one hour.
- RTL: content-direction helper now handles `ar`, `fa`, `he`, `ur` base codes and future BCP-47 suffixes such as `ar-SA`.
- CACHE INVALIDATION: successful content-language save updates `['me','languages']` and invalidates personalized recommendations + Latest feed.
- EMPTY DISCOVERY: personalized and Latest empty states point to language settings; Latest copy explains that no Ideas match selected languages.
- OUT OF SCOPE: per-request explicit `?languages=` filter controls, creator publishing UI, new UI-localization languages, comments/Spark/Save.
- TEST COMMANDS: typecheck, lint, Vitest, production build, Prettier check, runtime npm audit.
- ACCEPTANCE: reader can select multiple global languages, search the catalog, save them, and immediately receive filtered For You/Latest content while direct Idea URLs remain public.

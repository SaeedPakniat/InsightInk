## Product semantics

FE-018 manages moderator-hidden Ideas only.

- Moderator removal is the existing non-destructive `hidden` lifecycle state.
- A moderator may restore `hidden -> published`.
- Creator draft hard deletion remains permanent and is not represented as recoverable moderation trash.
- No frontend-only deleted-Idea recovery lifecycle was invented.

## Backend contract consumed

- `GET /api/v1/moderation/ideas/?status=hidden`
  - Moderator/Admin only.
  - `status=hidden` is required and is the only supported status.
  - Cursor paginated; backend page size is 25.
  - Ordered newest `updated_at` first, then highest id.
  - Safe list item:
    - `id`
    - `title`
    - `body_excerpt`
    - `language`
    - `status: "hidden"`
    - `creator: { id, display_name }`
    - `source: { id, type, title }`
    - `published_at`
    - `updated_at`
  - It intentionally does not expose full body, moderator identity, hidden timestamp, hidden note, email or metadata.
- `POST /api/v1/moderation/ideas/:ideaId/restore/`
  - Optional trimmed `note`, max 2000.
  - Restores `hidden -> published`.
  - Existing backend audit records the independent direct moderation action.

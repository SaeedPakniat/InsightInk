## Verified reporting backend contract

Reader-facing reporting currently exists only for comments:

```text
POST /api/v1/comments/<comment_id>/report/
```

- authenticated only;
- CSRF required;
- target Comment must be visible and belong to a published Idea;
- response 201 with public Report fields:
  - id
  - reason
  - details
  - status
  - created_at.
- locked reasons:
  - harassment
  - spam
  - inappropriate_content
  - other.
- details optional, trimmed, max 2000 characters.
- hidden/deleted/draft comments return 404.
- backend has no reader-facing Idea-report endpoint yet.
- backend has no report-history/read endpoint and no duplicate-report guard.

## Frontend reporting behavior

- Visible server-backed comment rows expose exactly one ownership action:
  - current user's comment -> Delete;
  - someone else's comment -> Report.
- While session ownership is still resolving, neither Delete nor Report flashes incorrectly.
- Optimistic local comments (negative temporary ID) expose neither action.
- Anonymous:
  - Report trigger is visible on public comments;
  - opening it shows Sign in to report;
  - login receives the current Idea route as return location.
- Authenticated:
  - inline report form expands below the comment body;
  - reason is required and uses only backend-locked choices;
  - optional details maxLength=2000;
  - localized character count;
  - Submit disabled until a reason is selected;
  - POST uses shared API client/session/CSRF behavior.
- Success:
  - form is replaced with a local Report submitted confirmation for the current mounted page state.
- Failure:
  - selected reason/details remain intact;
  - backend field validation is surfaced when present;
  - generic failure message otherwise.
- Own comments intentionally use Delete rather than Report.
- FE-012 does not claim knowledge of prior reports after refresh because the backend exposes no viewer report-history state.

## Visual/product boundary

- Reporting is intentionally quiet and subordinate to discussion.
- No modal framework or dependency added.
- No moderation/admin controls shown to ordinary readers.
- No Idea report action invented.
- Moderator queue/action UI remains a separate future milestone.
